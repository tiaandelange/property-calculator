# Google crawl readiness — Proplytic

Production site: **https://www.proplytic.co.za**

This project is a **Vite + React Router SPA** (not Next.js). Crawl assets are generated at build time from `frontend/seo/public-pages.json`.

## Crawl assets

| Asset | URL | Source |
| --- | --- | --- |
| robots.txt | https://www.proplytic.co.za/robots.txt | `frontend/public/robots.txt` (generated by `frontend/scripts/generate-crawl-assets.mjs`) |
| sitemap.xml | https://www.proplytic.co.za/sitemap.xml | `frontend/public/sitemap.xml` (generated at prebuild) |

Regenerate locally:

```bash
cd frontend
node scripts/sync-seo-data.mjs
```

## Private / blocked routes

`robots.txt` disallows crawling of authenticated, API, and transactional areas, including:

- `/api/`
- `/dashboard/`
- `/owned-properties/` (app portfolio routes)
- `/properties/` (legacy path pattern)
- `/tenants/`, `/leases/`, `/financials/`, `/statements/`, `/invoices/`
- `/settings/`, `/admin/`, `/documents/`
- `/auth/`, `/reset-password/`, `/update-password/`
- `/investment-calculator/` (authenticated calculator workspace)
- `/calculators/report/` (saved private reports)
- `/apply/` (tenant applicant tokens)
- `/confirm-email/`, `/account/`, `/subscription/`

These routes are **not** listed in `sitemap.xml`.

## Metadata and canonicals

- Canonical production origin: `https://www.proplytic.co.za` (`SITE_METADATA_BASE` / `PUBLIC_SITE_ORIGIN` in `frontend/src/lib/publicPageSeo.ts`)
- Default HTML shell: `frontend/index.html`
- Runtime tags: `PublicPageSeo` + page-level Helmet on marketing/legal/contact/login pages
- Build-time per-route HTML: `frontend/scripts/prerender-public-meta.mjs` (after `vite build`)
- Googlebot / social crawlers: Vercel `middleware.js` serves static preview HTML for matched public routes

Homepage includes JSON-LD (`Organization` + `SoftwareApplication`) via `HomePageSeo`.

**Intentionally noindex:** `/apply/:token` applicant pages (`noindex,nofollow`).

## Middleware

`middleware.js` only intercepts **known crawlers** (including Googlebot) on public marketing routes. It does **not** redirect unauthenticated users or block bots from `/`, `/pricing`, `/calculators`, `/reports`, `/contact`, `/login`, or `/signup`.

Static files `/robots.txt` and `/sitemap.xml` are served from `public/` and are excluded from the SPA rewrite in `vercel.json`.
